# Scratch-Kurs – Learning to code with Scratch, step by step

🇩🇪 [Deutsche Version](README.de.md)

A free learning path for **Scratch**, made for lower secondary school (Mittelschule) in Bavaria, Germany,
grades 5 and 6 (later up to grade 9). It follows the Bavarian curriculum (LehrplanPLUS Informatik).

**Live:** https://scratch.herrseibert.de

> The course is in **German**. Block names are exactly the ones of the German Scratch 3 editor
> (e.g. `wiederhole 10 mal` = *repeat 10*, `gehe 10 er Schritt` = *move 10 steps*).

## What's special?

- **Practice stage in the browser** (`assets/buehne.js`): drag Scratch-like blocks with mouse **or finger** (tablets!),
  run them with the pen, watch in slow motion or step by step (the running block lights up, loops show "round 2 of 4"),
  automatic check against a dashed target drawing.
- **Small steps for young learners:** predict first ("Überleg:"), then run, investigate, modify, make (PRIMM),
  Parsons puzzles, fill-in-the-gap scripts, bug-hunting tasks ("Fehlerdetektiv"), hint ladders, short quizzes where
  every wrong answer explains the misconception behind it.
- **No tracking, no cookies, no external resources.** Everything runs in the browser.

## Contents

| Folder | What's inside? |
|---|---|
| `index.html` | Course overview |
| `k5/`, `k6/` | Lessons for grade 5 and 6 |
| `assets/` | Styles, the practice stage, quizzes, language support |
| `downloads/` | Scratch project files (`.sb3`) and printables, where needed |

## Usage

Open `index.html` in a browser, or serve the folder with any static web server, e.g.

```
python3 -m http.server 8000
```
